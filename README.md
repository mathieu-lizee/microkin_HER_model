# microkin_HER_model
Microkinetic model to simulate the potential-dependent Tafel slope and Arrhenius parameters in 2-step HER mechanisms. The model includes typical electrochemical setups such as Rotational Disk Electrodes and Ultra Micro Electrodes and UME.

This is an upgraded version of the model presented in Ref [1]. Please cite if you use the model.

Lizée, M., Silva Olaya, A. R., Druce, J., Cuenya, B. R., & Oener, S. Z. (2026). Disentangling multistep kinetics by combining electrochemical Arrhenius analysis with micro-kinetic modelling. Faraday Discussions.

https://doi.org/10.1039/d5fd00127g


The notebook gives simple examples of how to use the model to predict experimental signatures.
